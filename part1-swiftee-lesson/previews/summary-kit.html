Summary Kit

The end-of-lesson summary from Swiftee & the Polygons: each idea shown on a card, said, and collected — then a tap on any card replays it. Press Play (sound on).

state: —

Mount it with your own ideas

The whole screen is data. Change the list, the lines and the visuals; the engine keeps the order, the timing and the states. The full notes are in the comment at the top of this file.

var kit = SummaryKit.mount(document.getElementById('summary'), {
  assets: '../assets/',
  concepts: [
    { id: 'vertex',   label: 'Vertex',   text: 'A vertex is a corner where two sides meet.', vo: 'p37a',
      visual: { draw: true, hi: [0], pulse: true, near: 0 } },
    { id: 'side',     label: 'Side',     text: 'A side is a straight line joining two vertices.', vo: 'p37b',
      visual: { hi: [0, 1], line: [0, 1, 'side'] } },
    { id: 'concave',  label: 'Concave',  text: 'In a concave polygon, atleast one diagonal goes outside.', vo: 'p37f',
      visual: { tone: 'concave', move: [0, 0, 0.08], line: [1, 4, 'out'] } }
  ],
  done: { text: 'Amazing! You explored all these polygon ideas!', vo: 'p37i' },
  onState: function (state, id) { console.log(state, id); },
  onFinish: function () { /* go to your ending */ }
});
kit.play();          // from a tap: audio needs a user gesture
kit.skipToEnd();     // everything collected, straight to the review
kit.replay('side');  // one card again, the others resting
kit.destroy();
